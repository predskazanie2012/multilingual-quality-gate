A SMALL, TRANSPARENT EXAMPLE

A workflow you can inspect.

The text, revision, findings, and scores are hand-authored for this synthetic example. They are not model outputs or benchmark results.

For this showcase, each dimension takes the lowest of three mock scores. The overall score is the lowest dimension, and the largest spread shows where reviewers differ most. This is an illustrative policy, not a description of a production system. An incomplete review produces no aggregate score.

No text entry, uploads, storage, analytics, or external services. Switching versions only changes the selected sample. A score is not a substitute for your own assessment.
