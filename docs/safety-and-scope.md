# Safety and scope

This is a newly authored, deliberately limited showcase. It is not a copy or a
deployment of the production system.

## Included

- Product overview and high-level architecture.
- A hand-authored English–Spanish lesson-announcement example.
- Generic mock reviewers and a small educational aggregation example.
- Screenshots of this local synthetic demo, without browser chrome.
- Dependency-free local serving and tests.

## Deliberately excluded

Production integrations and authentication, private configuration, model prompts,
credentials, account identifiers, session data, documents from real users,
business records, production datasets, operational logs and prior repository
history are not part of this showcase. No environment file is needed.

The local demo has no upload or free-text entry. All model responses and scores
are hand-authored fixtures. It performs no remote model requests and does not
persist documents in browser storage. Its content policy blocks outbound data
connections; the optional live-product link is ordinary navigation.

The local server serves only an explicit list of demo files. It is a development
preview, not a production server. No external packages or installation scripts
are required.

## Interpretation

Mock scores demonstrate interface behavior, not measured model performance,
translation accuracy or a benchmark. The educational policy is not a disclosure
of private production calibration, prompts or orchestration. Important content
still requires appropriately qualified human review.

The architecture describes the product idea. Agent reliability and governance
are future directions, not a claim that certification or a governance platform
is already available.

## Publication boundary

The initial snapshot is prepared locally for owner review. Publication requires
separate approval and a fresh check of the exact staged files. Visibility and
history of the working product repository must not be changed. Public visibility
does not itself grant a software licence; no licence grant is included here.
